# PRD: dex in the Browser via WebAssembly

**Status:** Draft  
**Author:** brainstorm session  
**Date:** 2026-04-03

---

## Overview

Run `dex` entirely in the browser — no backend, no logins required. Users pick a template, answer questions in a chat-style UI, and get a generated project they can download as a ZIP or push directly to GitHub/GitLab.

The existing `webapp/` (React + Vite chat frontend + Express server) already has most of the UI. The work is to eliminate the server entirely by compiling `dex-core` to WebAssembly and moving GitHub API calls fully client-side.

---

## Goals

1. **Free, no login required** — anyone can use it immediately
2. **Output options** — download as ZIP, push to public GitHub repo (optional PAT), push to GitLab (optional PAT)
3. **Privacy-first** — session-only storage (`sessionStorage`), no cookies, no tracking
4. **Confirm-to-clear on exit** — default yes; all session data wiped on tab close
5. **No data collected** — zero backend user data
6. **Optional anonymous telemetry** — template name only, explicit opt-in per session
7. **Chat-style UI** — conversational variable collection, not a form

---

## Non-Goals

- Custom/remote templates (embedded templates only in the browser build)
- `dex run` / task execution (no shell in the browser)
- Pass-through commands
- Skills installation
- Agent scaffolding (`dex agent new`) — possible future addition

## Architecture

```
Browser
  └── webapp/ (React + Vite, static)
        ├── src/lib/wasm.ts          ← new: WASM bridge
        ├── src/lib/api.ts           ← updated: remove server calls
        └── pkg/dex_wasm.js + .wasm ← generated by wasm-pack

crates/dex-wasm/                     ← new Rust crate
  └── exposes 3 wasm-bindgen fns:
        list_templates()
        get_template_variables(name)
        scaffold_template(name, vars_json)

crates/dex-core/                     ← minimal changes
  └── + scaffold_to_memory()
  └── + `fs` feature flag (gates std::fs / dirs / walkdir)
```

No server. GitHub API calls go directly to `api.github.com` from the browser (Device Flow only needs `client_id`, no secret).

## Implementation Plan

### Step 1 — `scaffold_to_memory` in dex-core

**File:** `crates/dex-core/src/scaffold.rs`

Extract the render loop into a private helper; add a new public function that returns files in-memory instead of writing to disk.

```rust
/// Render template files to an in-memory map — no filesystem writes.
pub fn scaffold_to_memory(
    template: &Template,
    variables: &HashMap<String, minijinja::Value>,
) -> Result<HashMap<PathBuf, String>, DexError>
```

The `dest.exists()` overwrite check is skipped in the in-memory path (always render all files).

Export from `crates/dex-core/src/lib.rs`. Add unit tests on the returned `HashMap`.

---

### Step 2 — `fs` feature flag in dex-core

**File:** `crates/dex-core/Cargo.toml`

```toml
[features]
default = ["fs"]
fs = ["dep:walkdir", "dep:dirs", "dep:shellexpand"]

[dependencies]
walkdir     = { workspace = true, optional = true }
dirs        = { workspace = true, optional = true }
shellexpand = { workspace = true, optional = true }
```

Gate filesystem-dependent code:
- `config.rs` public surface → `#[cfg(feature = "fs")]`
- `registry.rs` directory variants (`TemplateSource::Directory`, `load_directory_template`, `list_directory_templates`) → `#[cfg(feature = "fs")]`
- `scaffold()` (uses `std::fs`) → `#[cfg(feature = "fs")]`; `scaffold_to_memory` is ungated
- `lib.rs` re-exports for `config` and directory template fns → `#[cfg(feature = "fs")]`

**File:** `crates/dex-cli/Cargo.toml` — explicitly opt in:
```toml
dex-core = { workspace = true, features = ["fs"] }
```

### Step 3 — New `crates/dex-wasm/` crate

**`crates/dex-wasm/Cargo.toml`:**
```toml
[package]
name = "dex-wasm"
version = "0.2.0"
edition.workspace = true

[lib]
crate-type = ["cdylib", "rlib"]

[dependencies]
dex-core              = { workspace = true, default-features = false }
wasm-bindgen          = { workspace = true }
serde-wasm-bindgen    = { workspace = true }
serde                 = { workspace = true }
serde_json            = { workspace = true }
minijinja             = { workspace = true }
console_error_panic_hook = { workspace = true, optional = true }

[features]
default = ["console_error_panic_hook"]

[package.metadata.wasm-pack.profile.release]
wasm-opt = ["-Oz"]
```

Add to workspace `Cargo.toml`:
```toml
wasm-bindgen             = "0.2"
serde-wasm-bindgen       = "0.6"
console_error_panic_hook = "0.1"
```

**`crates/dex-wasm/src/lib.rs`** — three JS-exposed functions:

```rust
#[wasm_bindgen]
pub fn list_templates() -> Result<JsValue, JsValue>

#[wasm_bindgen]
pub fn get_template_variables(name: &str) -> Result<JsValue, JsValue>

#[wasm_bindgen]
pub fn scaffold_template(name: &str, variables_json: &str) -> Result<JsValue, JsValue>
```

Local `#[derive(Serialize)]` mirror types needed because dex-core structs only derive `Deserialize`:

```rust
#[derive(serde::Serialize)]
struct TemplateMetaJs { name: String, description: String, version: String }

#[derive(serde::Serialize)]
struct VariableSpecJs {
    name: String, prompt: String,
    #[serde(rename = "type")] var_type: String,
    required: bool,
    default: Option<serde_json::Value>,
    choices: Option<Vec<String>>,
    validate: Option<String>,
}
```

`scaffold_template`: parse `variables_json` → `HashMap<String, serde_json::Value>` → convert to `minijinja::Value` → call `scaffold_to_memory` → return `HashMap<String, String>`.

Build command:
```bash
wasm-pack build crates/dex-wasm --target web --out-dir ../../webapp/pkg --release
```

### Step 5 — Download as ZIP

Add `jszip`. In `webapp/src/components/widgets/FilePreview.tsx`:

```typescript
async function downloadZip() {
    const zip = new JSZip();
    for (const file of files) { zip.file(file.path, file.content); }
    const blob = await zip.generateAsync({ type: "blob" });
    const a = document.createElement("a");
    a.href = URL.createObjectURL(blob);
    a.download = `${projectName}.zip`;
    a.click();
}
```

### Step 7 — Privacy: session-clear + telemetry opt-in

**`webapp/src/App.tsx`:**

```typescript
useEffect(() => {
    const handler = (e: BeforeUnloadEvent) => {
        sessionStorage.clear();
        e.preventDefault();
        e.returnValue = "";
    };
    window.addEventListener("beforeunload", handler);
    return () => window.removeEventListener("beforeunload", handler);
}, []);
```

One-time per-session inline chat message for telemetry consent. If opted in, `navigator.sendBeacon()` fires with `{ template: name }` only. Default: no telemetry.
